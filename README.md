# AI를 이용한 게시글 자동 분류 및 문체변환 블로그 서비스

콘텐츠 창작의 부담을 줄이고, 생산성을 극대화하는 AI 기반 블로그 서비스

<br>

## 🎯 프로젝트 개요

MyLog는 단순한 블로그를 넘어 **AI를 활용해 창작자의 생산성을 혁신**하는 개인 블로그 플랫폼입니다.

사용자는 게시글을 작성하고 카테고리·태그로 정리할 수 있으며,  
**Google Gemini API**를 활용한 AI 기능으로 콘텐츠를 더욱 풍부하고 효율적으로 만들 수 있습니다.

### 주요 AI 기능
- **AI 자동 요약** — 긴 글의 핵심 내용을 한눈에 파악할 수 있도록 제공
- **AI 문체 변환** — 같은 내용이라도 원하는 톤앤매너(페르소나)로 자유롭게 변경
- **다중 채널 확장 지원** — 블로그 글을 인스타그램, 숏폼 등 다른 플랫폼에 맞는 스타일로 자동 변환

또한 **Google, Kakao, Naver 소셜 로그인**과 **JWT 기반 인증**으로 간편하고 안전한 서비스 이용이 가능합니다.

<br>

## 🚀 MyLog가 추구하는 가치

- **생산성 혁신** — 창작자는 ‘무엇을’ 전달할지만 집중하면, AI가 ‘어떻게’ 쓸지 도와줌
- **정보 소비 효율화** — 독자가 긴 글을 모두 읽지 않아도 핵심을 빠르게 파악
- **OSMU 전략 지원** — 하나의 콘텐츠를 여러 플랫폼에 최적화된 형태로 확장

MyLog는 창작자의 인지적 부담을 줄이고, 콘텐츠의 도달 범위와 가치를 극대화합니다.

<br>

## 📊 시장 분석

- 글로벌 생성형 AI 시장: 연평균 **30% 이상** 고속 성장
- 국내 블로그 시장: 네이버 블로그만 연간 **3.3억 건**의 글 발행
- 매일 120만 건 이상의 텍스트가 쏟아지는 포화 시장
- 독창적인 문체, 높은 가독성, 효율적인 정보 전달에 대한 수요 급증
- 한국어의 섬세한 문체와 존댓말 체계를 잘 이해하는 LLM 기술 상용화로 서비스 도입 적기 도래

크리에이터 이코노미 성장과 생성형 AI 기술의 발전으로 **지능형 블로그 서비스**의 필요성이 크게 증가하고 있습니다.

<br>

## 🔍 기존 서비스와의 차별점

| 구분                | 기존 블로그 플랫폼 (네이버, 티스토리 등) | **MyLog** |
|---------------------|------------------------------------------|-----------|
| 콘텐츠 작성         | 사용자 수동 작성                         | **AI 지원 작성** |
| 문체 조정           | 수동 편집                                | **AI 자동 문체 변환** |
| 요약 기능           | 없음                                     | **AI 자동 요약** |
| 다중 플랫폼 확장   | 수동으로 별도 작성                       | **AI가 플랫폼별 최적화** |
| 창작자 부담         | 높음                                     | **획기적으로 감소** |

### 핵심 차별점
- **지능형 문체 변환** — 원하는 페르소나에 맞춰 글의 톤과 구조를 자동 변경
- **AI 자동 요약** — 독자의 이탈률 방지와 정보 소비 효율 극대화
- 단순 기록 공간이 아닌, **콘텐츠 생산성·도달 범위·가독성**을 모두 높여주는 **지능형 콘텐츠 허브**

MyLog는 AI를 통해 창작자의 생산성을 높이고, 독자에게는 더 나은 읽기 경험을 제공합니다.
